    3. Clear Space & Minimum Size
    X X

    Clear Space Rule: Maintain a minimum clear space equal to the height of the logo's tallest element ("X") on all sides. This ensures visual breathing room and brand integrity.

    6. Logo Usage on Dark Backgrounds

    Always use the white or light variant of the logo on dark or saturated backgrounds. Maintain contrast ratios ≥ 4.5:1 for accessibility. Never overlay primary blue or black logos on dark surfaces.

    7. Usage Guidelines
    check_circle Do This
    • Use approved logo variants for context
    • Maintain minimum clear space (Section 3)
    • Use SVG for digital, high-res PNG for print
    • Test contrast ratios for accessibility
    • Use Primary Blue (#2563FF) for key CTAs
    cancel Avoid This
    • Stretching, skewing, or rotating the logo
    • Placing logo on busy backgrounds without padding
    • Using unapproved colors or effects
    • Reducing logo below minimum size
    • Using primary logo on dark backgrounds

    ✗ No clear space
